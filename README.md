# Python untuk Pemula

Repositori ini berisi latihan dari kursus Python untuk Pemula di Santrikoding.

## Ringkasan Materi

- Variabel dan tipe data dasar (angka, string, boolean)

## Cara Menjalankan

1. Clone repositori ini
2. Buat virtual environment: `python3 -m venv venv`
3. Aktifkan: `source venv/bin/activate`
4. Jalankan program: `python variable_numbers.py`
